# AI literacy deck (Spanish - Costa Rica)

*Part of the [AI Enablement Toolkit](../../README.md).*

**[Open the deck →](https://luispsalas.github.io/ai-enablement-toolkit/literacy/deck/alfabetizacion-ia-deck.html)** *(an interactive HTML deck; GitHub shows the file itself as source code, so use this link to view it)*

*Alfabetización en IA: Guía de referencia.* A 19-slide deck in Spanish that explains how AI systems work, where they fail, and how to use them responsibly, for teams and decision makers without a technical background.

| | |
|---|---|
| **Audience** | Non-technical teams and decision makers |
| **Language** | Spanish |
| **Length** | 19 slides: a cover, eight sections and two appendices |
| **Context** | Aligned with Costa Rica's national AI strategy (ENIA 2024–2027) and the OECD definition of an AI system |
| **Edition** | October 2026 |
| **Levels** | Each slide is tagged by the audience it mainly serves: *Comprensión* (awareness, for all staff), *Operativo* (for people who use AI in their work) and *Gobernanza* (for people who decide about its use and answer for it) |

## Structure

The order puts governance and risk before tools, and prompting after both, so people learn what can go wrong before they learn how to go faster.

| # | Section |
|---|---|
| 00 | The current state of AI |
| 01 | AI and data governance framework |
| 02 | Data governance roadmap |
| 03 | Organizational blind spots |
| 04 | AI security |
| 05 | Assessing AI tools |
| 06 | Prompts and responsible use |
| 07 | Next steps |
| A·1 | Glossary: 38 terms in five groups, Spanish with the English term, taken from the toolkit's [English–Spanish glossary](../glossary.md) |
| A·2 | References and further reading |

## What to know before using it

- **It is written for a Costa Rican audience.** The national strategy and local sources set its context; for another country, replace section 00's framing and the references' local block.
- **Its references were checked in October 2026.** The title, publisher and year of each one were confirmed on the publisher's own page, and statistics that could not be confirmed there were removed.
- **It is a single self-contained HTML file.** Open it in a browser; no install, no network needed once downloaded.
